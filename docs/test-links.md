# 桌面版下载入口验证

## 独立下载中心（2026-10-27）

- 下载页地址为 `/[locale]/desktop`，顶部和手机菜单的入口在新标签页打开，保留网页下载任务。
- 下载页顶部栏的 GitHub、反馈、历史版本分别指向桌面客户端仓库、Issues 与 Releases 列表，均在新标签页打开；顶部栏、标题区与手机菜单均不展示发布说明入口。手机菜单使用相同链接。切回网页版后恢复网页仓库、站内反馈和原更新日志弹窗。路径判断不受 `source` 查询参数影响；768 px、1024 px 俄语顶部栏与 390 px 手机布局无横向溢出。
- 桌面并排展示 Windows、macOS、Linux 安装包，手机纵向展示；安装说明在各系统卡片内直接显示。390 px 浏览器可视宽度下无横向溢出。
- 真实版本接口返回 0.5.2，三张卡片展示对应的 GitHub 安装包地址及文件大小。
- 页面直接在服务端读取共享的正式版缓存，把安装包信息随初始 HTML 返回。实际抓取的原始 HTML 包含三个安装包链接，没有“正在获取最新版本”；浏览器无需在每次进入时重新请求版本接口，只有用户手动重试时才请求。
- 排查加载停留时发现，开发配置把 `lucide-react` 排除在依赖预打包之外。全新浏览器会话捕获到 1,835 个请求，其中 1,724 个来自图标库，版本请求在页面请求后约 4,132 ms 才发出。恢复图标库预打包后，同一页面降为 104 个请求，图标库仅 1 个请求，版本请求约 394 ms 发出并返回 HTTP 200。
- 客户端重试请求保留 12 秒超时，失败后显示重新获取与发布页入口。浏览器注入始终不返回的请求后，约 12.5 秒退出加载；恢复真实请求并点击重新获取后，显示 0.5.2 与三个安装包链接。临时拦截已清理。离开页面时取消请求并清理定时器。
- `pnpm exec tsc --noEmit`、`pnpm lint`、`pnpm build` 与 `git diff --check` 通过。

## 入口和弹窗

- 桌面顶部栏左侧“下载桌面版”打开弹窗，展示本地解析、批量任务、内置引擎三个优势。
- 默认识别桌面操作系统，也可手动选择 Windows x64、macOS Apple 芯片、Linux x64。
- 切换系统后，下载按钮、安装包格式、真实文件大小与安装说明同步更新。
- macOS 在下载按钮之前明确显示 Apple 芯片、macOS 13 及以上、暂不支持 Intel Mac。
- 安装说明可展开；Esc 关闭弹窗后，焦点回到桌面下载按钮。
- 手机从顶部菜单进入下载弹窗，菜单随之关闭。iPhone 14（390 × 844）不自动选择电脑系统；选择 macOS 后，页面和弹窗均无横向溢出。
- 手机关闭后，焦点回到“打开菜单”，页面恢复可点击状态。
- 简体中文深浅色主题、日文手机布局已在浏览器查看；六种语言的字段结构与三系统安装步骤完整。
- 文案补充：“本地解析与保存”新增“支持更高清画质下载”，六种语言同步更新；实际中文弹窗文字已确认，弹窗内容宽度与可视宽度一致，无横向溢出。类型检查与差异空白检查通过。

## 失败与恢复

在浏览器临时让桌面版版本请求失败，验证了失败提示、禁用未获得有效地址的下载按钮、重新获取按钮及 GitHub 发布页入口。已获取版本后请求失败，旧版本下载链接仍保留，并显示版本暂时无法确认的提示。恢复真实请求后，通过重新获取恢复最新正式版信息。临时请求拦截已移除。

服务端复用 vinext 的框架缓存，正式版信息每 300 秒重新验证；成功响应提供浏览器/共享缓存和 stale-while-revalidate，失败响应不缓存。安装包直接从 GitHub 下载，网站不转发安装包文件。
