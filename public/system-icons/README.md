# System brand icons

Unmodified SVG artwork from [Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/tree/11.15.0/icons):

- `windows.svg`: `windows11.svg`, Windows logo.
- `apple.svg`: `apple.svg`, Apple logo.
- `linux.svg`: `linux.svg`, Linux Tux logo.

Simple Icons is distributed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/11.15.0/LICENSE.md). Brand marks belong to their respective owners. CSS masks apply the page's foreground color for both themes without changing the SVG paths.
